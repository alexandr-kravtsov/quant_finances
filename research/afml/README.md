# AFML research

Основная последовательность `JERICHON_mark` находится в `mark_1`–`mark_7` (см. `../README.md`). Дополнительные AFML эксперименты разнесены по папкам `afml_01_*`–`afml_08_*`. `feature_lab/` — отдельная ветка исследования микроструктурных признаков и их причинной доступности. `diagnostics/` содержит ранний notebook диагностики волатильности.

Результаты `afml06_outputs`, `afml07_outputs` и parity/ablation outputs сохранены в подпапках `results/` соответствующих экспериментов. Два неидентифицированных `regime_research*_outputs` каталога не включены.
